# Потребители UiKit

| Репозиторий | Ветка | Сабмодуль | Проверки |
|---|---|---|---|
| SuselMan/Sports (Kektrack) | main | frontend/UiKit | frontend: tsc --noEmit, vite build; взаимодействия изменённых компонентов |
| SuselMan/health (новый стенд здоровья и сервисов) | redesign/ui-kit | frontend/UiKit | frontend: npm run typecheck, npm run build; мобильные/desktop страницы обоих профилей |

Оба приложения должны закреплять один проверенный SHA.
Действующий старый HTML-интерфейс здоровья и старые «Мои сервисы» пока UiKit
не используют; они не считаются перенесёнными и не переключаются автоматически.
Мои сервисы на новом стенде используют тот же frontend health, а не отдельную копию UiKit.

При изменении списка обновлять этот файл в той же задаче, что и подключение/отключение.
При изменении версии фиксировать SHA в gitlink потребителей, а результаты проверок —
в их журналах задачи. Не хранить здесь приватные URL и пользовательские данные.
