# Потребители UiKit

| Репозиторий | Ветка | Сабмодуль | Проверки |
|---|---|---|---|
| SuselMan/Sports (Kektrack) | main | frontend/UiKit | frontend: tsc --noEmit, vite build; взаимодействия изменённых компонентов |
| SuselMan/health (здоровье обоих профилей и мои сервисы) | master | frontend/UiKit | frontend: npm run typecheck, npm run build; мобильные/desktop страницы обоих профилей |

Приложения закрепляют опубликованные проверенные SHA и обновляют их независимо.
Здоровье обоих профилей и «Мои сервисы» используют одну сборку frontend health.
Данные и авторизация профилей разделены на сервере; переключателя пациента нет.
Изменение сабмодуля само по себе не означает production deploy.

При изменении списка обновлять этот файл в той же задаче, что и подключение/отключение.
При изменении версии фиксировать SHA в gitlink потребителей, а результаты проверок —
в их журналах задачи. Не хранить здесь приватные URL и пользовательские данные.
