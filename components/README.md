# Общие компоненты

Компоненты не содержат API-запросов, маршрутов приложений и правил оценки данных.
Используют токены темы. По прямому запросу владельца добавлены только два
цвета значений из Tonome; текст на красной заливке — белый, на светло-бирюзовой — существующий
тёмный цвет палитры.

- `Collapsible`: нативный `details/summary`, `title`, содержимое, стандартные
  `open/onToggle/id` и остальные атрибуты details. Поддерживает управление
  извне и собственное нативное раскрытие.
- `MetricCard`: `title`, `value`, `unit`, `icon`, `description`;
  `orientation="horizontal"` или стандартная вертикальная компоновка.
  Форматирование, вычисления и смысл статуса задаёт приложение.
- `ScrollNav`: `items: {id,label,icon?,disabled?}[]`, `value`, `onChange`,
  обязательное доступное название `label`. Горизонтальная прокрутка касанием,
  без scrollbar, активный пункт удерживается в видимой области;
  стрелки/Home/End перемещают фокус, Enter/Space выбирают пункт.
- `ChartHatch`: SVG-pattern с `id`, внутри `defs`. Мелкая диагональная
  штриховка в семействе основного акцента; область и значение референса
  определяются графиком приложения.

## Совместимые расширения существующих компонентов

- `ToggleDropdown nativeOnMobile`: при одиночном выборе на ширине до 700 px
  **или** с coarse pointer используется настоящий `select`. На desktop остаётся
  Dropdown. `nativeProps` передаёт доступное имя/id/disabled, `nativeLabels`
  задаёт строковые названия для опций с React-содержимым в `voc`.
  По умолчанию поведение прежнее; multiselect не превращается в single select.
- `Chip onClick/selected/disabled`: фильтр-кнопка с `aria-pressed`, без обводки, на вторичной поверхности.
  Прежний вариант с `close` для удаляемых тегов сохранён.
- `Button shape`: `default` (прежний вид), `rounded`, `pill`.
- `Input rounded/density="compact"`: необязательные варианты оформления.
- `Card rounded/padding="lg"`: необязательные варианты; обычные HTML-атрибуты
  передаются корневому элементу. Прежние значения по умолчанию сохранены.
- `Modal`: Escape, цикл Tab и возврат фокуса, включая открывающий элемент
  в Shadow DOM. `useClickOutside` учитывает composedPath.

Нативные ссылки на внешние приложения, таблицы и SVG-геометрия не заменяются
виджетами с другим назначением. `Link` предназначен для react-router;
`Sidebar` — для модальной боковой панели, а не постоянного desktop-меню.

- `ValueBadge status`: normal (прозрачно), high (красный Tonome), low
  (бирюзовый Tonome), unknown (вторичная поверхность). При onClick использует
  существующий Button. Классификации, границ и медицинских норм в компоненте нет.
